# Beginner Python Projects

These are starter projects to run, review, and understand before listing them as completed work.

## 1. Student Record Management System
- Add, view, search, and delete student records
- Validates marks and duplicate IDs
- Saves data locally in `students.json` using JSON

Run:
```bash
python student_record_management.py
```

## 2. Expense CSV Analyzer
- Reads expense records from a CSV file
- Calculates total spending and totals by category
- Handles invalid amounts and reports input errors

Run:
```bash
python expense_csv_analyzer.py sample_expenses.csv
```
